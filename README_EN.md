# Single-Phase Power Analyzer

This repository contains a TI development-board based single-phase power analyzer project for Problem H of the 2024 National Undergraduate Electronics Design Contest. The work won a provincial first prize.

## Project Summary

The project focuses on single-phase power measurement and analysis. It is intended as a reference implementation for embedded measurement, signal sampling, electrical-parameter calculation, and competition documentation.

## Content

- Core project README and competition description.
- Problem document: `B题_单相功率分析仪.pdf`.
- Reference material for a TI-board implementation of a single-phase power analyzer.
